# Sources that set rules

These public posts and papers are why the playbooks have this shape. Do not treat them as a bibliography to recite.

- Thariq (@trq212), 10 Jun 2026, post `2064826394589442448`. The Fable launch video was edited in Claude Code with transcription, ffmpeg, a grade, the Figma MCP, and Remotion. The operator did not touch an NLE. Rule: a programmatic compositor plus ffmpeg is a full edit path.
- Thariq (@trq212), 7 Jul 2026, post `2074617788216561729`. The harness is scripts plus Remotion assets. Rule: the edit stays as files an agent can rerun.
- Ole Lehmann (@itsolelehmann), 23 Sep 2026, post `2102653764255551761`. A reference goes in. The agent matches pacing, transitions, and animated text, stays in an editable project, and takes a one-line revision. Rule: the effect playbook, and an editable project beside the MP4.
- Nick Spisak (@NickSpisak_), 24 Sep 2026, post `2103241047325200851`. He demonstrates a vibe edit with Claude Opus 5.5. Rule: Opus is the taste and redesign lane. Execution stays on the Grok lane because this skill assigns tools there.
- Mahnoor Faisal, XDA Developers, 29 Jun 2026, "Forget vibe-coding apps, people are now vibe-editing videos in Claude Code". Same Fable edit, reported independently. Rule: the code path is the public meaning of vibe editing, not a filter preset.
- MindStudio, 24 Sep 2026, "Claude Opus 5.5 vs GPT-6 Astra". On a sizzle and an explainer, Opus led on taste. Astra finished faster. Rule: Astra reads and plans. Opus redesigns.
- arXiv:2601.08565, Rewrite Kit. Human viewers scored pacing, vibe, and transitions. Frame scores missed that. Rule: fidelity carriers are temporal and stylistic.
- arXiv:2609.12769, agentic video editing. Complexity is how music, hits, titles, and silence line up. Rule: clocks are a required array, not a note on a clip.
- CineD, 22 Sep 2026, Eddie AI v4. The agent cuts to beats and can join a Resolve or Premiere project. Rule: Resolve is a join path when that project is the deliverable.
- Higgsfield posts that say "vibe editing" and mean a look preset (for example @higgsfield_ai, 13 Jan 2026, post `2011155980835570143`) are not a deconstruction. A LUT name can be one `grade.name`. It is not the model.

DreamFort Edit Video (18 Sep 2026) re-renders picture content and keeps the camera move. That is a picture-replace job. It is out of scope unless the operator asks for it.
